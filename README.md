# Проект: Мобильное приложение "Brew & Go"

## 📝 Описание проекта
"Brew & Go" — это концепт мобильного приложения для сети кофеен, позволяющий пользователям делать предзаказ напитков и забирать их в удобное время без ожидания в очереди. 

**Реклама проекта** представлена в виде серии из 5 сторис (формат 1080x1920), которые ведут пользователя от проблемы (утренняя очередь) к решению (скачивание приложения).

## 🎨 Объяснение цветовой палитры
При разработке дизайна интерфейса и рекламных креативов была выбрана «теплая» цветовая палитра, ассоциирующаяся с натуральным кофе, уютом и теплом. 

*   **Шоколадный / Темно-коричневый (Chocolate Brown) `#6E4A38`** — Основной брендовый цвет (используется для шапки приложения, кнопок "Заказать" и акцентов). Ассоциируется с обжаренными кофейными зернами, придает интерфейсу премиальности и надежности. Отлично контрастирует со светлым фоном.
*   **Кремовый / Молочный (Cream / Off-white) `#F9F5EE`** — Цвет фона. Создает мягкую, ненавязчивую атмосферу, имитирует цвет молочной пенки или бумажного стакана. Не режет глаза, в отличие от чистого белого, и делает приложение "уютным".
*   **Белый (White) `#FFFFFF`** — Цвет карточек товаров. Используется для визуального выделения блоков с напитками, создавая эффект "слоя" над кремовым фоном.
*   **Салатовый / Травяной (Light Green) `#6DB75D`** — Акцентный цвет для цен. Свежий, природный оттенок, который отлично читается на белом фоне, не сливается с коричневым и мягко привлекает внимание к стоимости продукта.

## 📁 Структура репозитория
*   `/stories` — готовые рекламные сторис (4-5 шт).
*   `/screenshots` — скриншоты интерфейса мобильного приложения.
*   `/assets` — графика, логотипы, иконки, фоны.

## 🛠 Инструменты
*   **Figma** — проектирование UI/UX интерфейса приложения.
*   **Flyvi / GIMP** — сборка и оформление рекламных сторис.
